# HRM system

## Описание

SPA-приложение для управления сотрудниками компании, их профилями и профессиональными навыками.

## Краткая функциональность

- Авторизация пользователя
- Регистрация новых пользователей
- Просмотр пользователей,зарегистрированных в системе в удобной таблице
- Сортировка пользователей по разным параметрам: Имя, Фамилия, департамент, позиция, email
- Поиск сотрудника по ФИО
- Изменение пользовательских данных
- Добавление новых сотрудников
- Удаление сотрудников
- Адаптивный интерфейс

## Список зависимостей

Основнвые зависимости:

- nuxt
- vue
- pinia
- zod
- primevue
- cv-graphql

## Структура проекта

В папке source(src) есть несколько папок, которые каждая отвечает за свою задачу:

- assets — папка с базовыми стилями
- components — тут храняться кастомные компоненты
- composables — папка с кастомными composables
- graphql — папка с graphql queries и mutations и типами для их реализации.
- layouts — тут храняться layouts, которые являются основой для страниц.
- middleware — здесь храняться функции, которые выполняются пере рендерингом страниц
- pages - страницы приложения, по которым имеются роуты
- plugins - настройка и подключение сторонних компонентов к приложению
- tests - тут храняться unit-тесты
- types - типы, используемые в приложении
- utils - вспомогательные функции

## Инструкция по запуску

1. Клонируйте репозиторий

`https://github.com/Lis1459/HRM-System-practice`

2. Перейдите в папку с проектом

`cd HRM-System-practice`

3. Запуск в режиме разработки

`npm run dev`

После запуска проект будет доступен на по адресу:

`http://localhost:3000`

4. Конечная сборка проекта (для продакшена)

`npm run build`

# Тесты

Для запуска unit-тестов воспользуйтесь командой:

`npm run test`
